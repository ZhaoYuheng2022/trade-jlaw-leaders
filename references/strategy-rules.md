# 入场、风控与退出规则

## 1. 决策顺序

市场状态 → 个股长期趋势 → 题材相关性／价格领导力 → 形态质量 → 突破触发 → 追价与止损距离 → 账户仓位 → 退出。

任何高层过滤失败，都不能靠一个漂亮的低层触发抵消。

## 2. 视频支持的共同规则

- 只做第二阶段／明确上升趋势的右侧机会，不在长期下跌中博反弹。
- 成交量放大是加分项，不是所有突破的必要条件。
- 2h／4h 可帮助识别触发；“不短于 2 小时”的规则用于 Pullback／Swing 视频语境。
- 初始止损由结构决定，不能向下放宽；价格止损距离不等于账户风险。
- 入场前选择 Swing 或 Trend，不能亏损后改成长线，也不能因卖后上涨而否定原纪律。
- 市场不健康时减少股票比例、保留现金；组合具体百分比并未由视频给出。

## 3. 变体 A：Pullback Recovery

1. 第二阶段，优先早期／中期，一浪高于一浪。
2. 拉回自然、温和、较短；避免大阴、放量下跌、明显跌破 50 日线和松散结构。
3. 不在拉回下跌途中买；等重新上升并突破短期下降趋势线，最好有小型整固。
4. 通常离开突破参考点 2%–3% 不追。
5. 止损放结构前低下方；入场至止损通常为 8%–10% 内，理想约 5%–6%。

趋势线端点、swing 确认、自然拉回阈值和止损缓冲没有完整算法，回测必须另列假设并防止未来函数。

## 4. 变体 B：紧密区间 Swing Trade

1. 明确上升趋势。
2. 区间至少数天，宽度越窄越好，最好不超过 5%。
3. 突破区间才买，不提前在区间内埋伏。
4. 止损放区间下方；平均目标约 8% 时，已升 4% 以上再追会显著压缩剩余空间。
5. Swing 只交易一个子浪，目标约 5%–15%，并要求潜在回报至少约 2R。
6. 走得太慢或不动可考虑时间退出，但视频未给固定天数。

不要把 Pullback 的 2%–3% 追价规则与 Swing 的 4% 案例推算混为同一参数。

## 5. 市场过滤候选

- 指数在 50 日／200 日线上且均线能发挥支持，属于较健康背景。
- 出货日：前段定义为指数下跌且成交量高于前一日和 50 日均量；轻微上涨但滞涨放量也可能算。后续案例有宽松口径，需分开测试。
- 2–4 周约 4 个或以上出货日是高度警示，不是独立预测顶部的证明。
- 指数上涨而成分股位于 50／200 日线上的比例持续下降，属于宽度背离。
- 延伸升势后的急涨，再出现数月至一年最大单日下跌，属于强烈风险信号。

以上主要用于市场总敞口，不应机械替代个股止损。

## 6. 仓位——工程补全

```text
每股风险 = entry − stop
风险预算 = equity × account_risk_pct / 100
股数 = floor(风险预算 / 每股风险)
再受单股仓位、手数和流动性上限约束
```

账户风险比例、最大持仓数、行业上限、总敞口和时间退出参数均需由使用者设定并回测。示例中的 0.5% 只是研究起点，不是 JLaw 原规则或实盘建议。

## 7. 仍需验证

“更适配近年市场”目前只是研究假设。需要与简单趋势突破、买入持有或其他基准做相同样本、成本和样本外比较，不能凭教学案例或比赛叙述下结论。
